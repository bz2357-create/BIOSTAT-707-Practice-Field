# BIOSTAT 707 Checkpoint 1

With Pixi installed and the supplied files in `data/set-a/` and
`data/Outcomes-a.txt`, run `pixi run --locked checkpoint1` from the repository
root. This installs the locked environment and creates `output/checkpoint1.html`,
`output/set-a_long.csv`, and `output/set-a_wide.csv`, plus supporting audit CSVs
and figures under `output/`. Inputs are read-only; the analysis does not download
data. The HTML is self-contained. Only the rendered HTML is committed among
the generated outputs.
